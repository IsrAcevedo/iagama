# IAGAMA

Landing Page y tienda virtual para un local de reparación y mantenimiento de computadores.

## Tecnologías

- Flask
- MySQL
- Tailwind CSS

## Características

El proyecto integra una Landing Page responsive para presentar la empresa, sus servicios, promociones y canales de contacto, junto con una Tienda Virtual que permite a los clientes explorar productos, consultar detalles y realizar pedidos de forma intuitiva.

- Landing Page atractiva y optimizada para dispositivos móviles.
- Catálogo de productos con búsqueda y categorías.
- Gestión de productos e inventario.
- Panel de administración para gestionar el contenido de la tienda.
- Base de datos relacional para almacenamiento de información.
- Interfaz moderna desarrollada con Tailwind CSS.
- Arquitectura basada en Flask siguiendo buenas prácticas de desarrollo.
- Tecnologías utilizadas
- Backend: Flask (Python)
- Base de datos: MySQL
- Frontend: HTML5, Tailwind CSS y JavaScript
- Motor de plantillas: Jinja2
